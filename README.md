# Stockcast

한국투자증권(KIS) Open API를 사용하는 국내주식 모의투자 데이트레이딩 도구입니다. CLI로
현재가·잔고·신호·주문을 확인할 수 있고, localhost 웹 대시보드에서 종목 검색과 모의 자동매매를
제어할 수 있습니다.

> 이 프로그램은 투자 수익을 보장하지 않습니다. 자동매매는 반드시 모의투자에서 충분히
> 검증하고 호출 제한, 미체결, 휴장일, 세금과 수수료를 별도로 확인하세요.

## 설치와 실행

Python 3.11 이상이 필요합니다.

```powershell
py -m venv .venv
.venv\Scripts\Activate.ps1
pip install -e .
```

Windows에서는 [Stockcast.bat](Stockcast.bat)을 실행하면 기존 8787 포트의 Stockcast 서버를
종료하고 최신 서버를 시작한 뒤 브라우저를 엽니다. 직접 실행하려면 다음 명령을 사용합니다.

```powershell
python -m stockcast.web
```

브라우저 접속 주소는 `http://127.0.0.1:8787`이며 외부 네트워크에는 바인딩하지 않습니다.

## 인증 파일

로그인 화면에서 선택한 환경에 따라 다음 로컬 파일을 읽습니다.

- 모의투자: `.env.paper`
- 실전투자: `.env.live`

```dotenv
KIS_APP_KEY=
KIS_APP_SECRET=
KIS_ACCOUNT_NO=
KIS_ACCOUNT_PRODUCT_CODE=01
KIS_ENV=paper
STOCKCAST_ALLOWED_SYMBOLS=
STOCKCAST_MAX_ORDER_KRW=100000
STOCKCAST_ALLOW_LIVE=false
```

API 키, 시크릿과 계좌번호가 든 파일은 Git에 포함하지 마세요. 자동매매 엔진은 실전 계좌에서
시작할 수 없습니다. 주문 허용 종목을 비워두면 전체 후보를 허용하고, 값을 입력하면 그 종목
안에서만 주문합니다.

## 데이트레이딩 자동매매

자동검색은 KIS 거래량 순위 API를 이용해 유동성 후보를 가져옵니다.

- 포함: 거래금액 상위 개별 보통주
- 제외: 일반 ETF, 레버리지 ETF, 인버스 ETF, 우선주
- 1차 가격 범위: 1,000원 이상 500,000원 이하
- 1차 거래량: 10만 주 이상

후보별 당일 1분봉을 조회해 다음 규칙으로 판단합니다.

- 진입 시간: 평일 09:10 이상 14:50 미만
- 매수: 5개 봉 이동평균이 20개 봉 이동평균보다 높고 현재가가 직전 5개 봉 최고가 돌파
- 매수 품질: 직전 고가를 기본 0.2% 이상 돌파해야 하며 매도 후 같은 종목은 기본 30분간 재진입하지 않음
- 거래량·VWAP: 직전 완료 분봉 거래량이 최근 평균의 기본 1.5배 이상이고 현재가가 당일 분봉 VWAP 위일 때만 진입
- 매도: 가격이 5개 봉 이동평균 아래에서 기본 2개 봉 연속 확인되거나 손절률·익절률에 도달
- 수익 추적: 수익률 1% 도달 후 매수가 대비 0.1%까지 밀리면 본전 보호, 2% 도달 후 고점에서 0.7% 하락하면 추적 매도
- 과매매 제한: 종목별 하루 최대 2회 진입, 전체 하루 최대 10회 왕복 거래
- 시간 필터: 09:10~11:20 및 13:00~14:50에만 신규 진입해 기본적으로 점심시간 거래를 피함
- 신규 진입 중단: 14:50
- 당일 청산: 15:15~15:20 사이에 봇이 매수한 보유분 전량 시장가 매도
- 범위: 현재 실행에서 자동매매가 매수한 포지션만 관리하며 기존 수동 보유분은 건드리지 않음

### 일일 목표와 거래 리포트

- 기본 일일 목표 수익률은 10%이며, 계좌 총평가금액 기준 목표 도달 시 그날의 신규 매수를 중단합니다.
- 매수 수량은 `최신 총평가금액 × 종목당 투자 비중 ÷ 현재가`로 계산하고 소수점 이하는 버립니다. 계산 예산이 1회 최대 주문금액보다 크면 안전 설정의 주문금액 한도를 적용합니다.
- 당일 수익률이 음수이거나 목표의 절반 이상이면 종목당 투자 예산을 절반으로 줄입니다. 목표 미달을 만회하기 위해 비중을 늘리지는 않습니다.
- 기본 일일 손실 한도는 3%이며, 도달하면 신규 진입을 중단하고 현재 실행에서 매수한 포지션을 청산합니다.
- 계좌 수익률이 기본 1% 이상 도달한 뒤 당일 최고 수익률에서 0.5%p 이상 반납하면 수익 보존을 위해 신규 진입을 중단합니다.
- 리포트는 첫 잔고 조회 후 상태·복구용 `.stockcast/reports/YYYY-MM-DD.json`과 사람이 읽는 `.stockcast/reports/YYYY-MM-DD.md`에 함께 갱신되고, 장 마감 청산 또는 수동 중지 시 최종 상태가 기록됩니다. 파일은 임시 파일을 완성한 뒤 교체해 기록 도중의 불완전한 리포트를 남기지 않습니다.
- Markdown 매매일지는 장 마감 요약, 계좌 평가손익, 체결 기준 거래별 비용 전 손익, 승률, 종목 선정·진입 차단 사유, 미체결, 잔여 포지션, 운영 오류, 잘한 점·문제점·다음 거래일 액션 순서로 정리됩니다.
- 수익률은 프로그램이 당일 처음 조회한 KIS 잔고의 총평가금액과 최신 총평가금액을 비교합니다. 주문 목록에는 진입·청산 사유와 KIS가 반환한 주문번호를 기록하고, KIS 일별 주문체결조회 결과는 `executions`에 별도로 저장합니다. 매매일지의 전략 체결 통계에는 주문번호가 일치하는 체결만 포함해 수동 주문과 구분합니다.
- 체결 내역은 API 호출 제한을 줄이기 위해 최대 10분 간격으로 동기화하며 장 마감 청산 또는 수동 중지 시 다시 조회합니다. 모의투자 잔고 반영 지연에 따라 최신 주문이 즉시 나타나지 않을 수 있습니다.
- 장중 서버를 재시작해도 당일 리포트에서 종목별 진입 횟수, 마지막 청산 시각과 미청산 봇 포지션을 복원해 과매매 제한을 이어갑니다.
- 자동 검색 후보의 VWAP·상대 거래량·전략 신호 탈락 횟수와 실제 진입을 막은 시간·일일 한도·재진입·보유 수 제한을 누적합니다. 이 통계는 한 거래일만으로 기준을 완화하기보다 여러 날의 반복 패턴을 복기하는 용도입니다.

일일 10%는 전략의 중단 기준일 뿐 달성 또는 수익을 보장하지 않습니다. 모의투자 체결 지연, 수수료와 세금, 슬리피지 및 API 장애를 포함해 충분히 검증한 뒤 설정을 조정하세요.

프로그램이 꺼지거나 네트워크·KIS API 장애가 발생하면 마감 청산을 보장할 수 없습니다. 주문
체결·미체결 조회와 재시작 복구가 추가되기 전까지는 대시보드를 감시하면서 소량으로 시험하세요.

모의투자 API는 초당 호출 제한이 낮으므로 KIS 요청은 직렬화하고 최소 간격을 적용합니다.
`EGW00201` 조회 오류는 지연 후 재시도하지만, 중복 체결 위험 때문에 주문은 자동 재전송하지
않습니다.

## CLI

```powershell
stockcast quote 005930
stockcast balance
stockcast signal 005930 --short 5 --long 20
stockcast order buy 005930 1
stockcast order buy 005930 1 --execute
```

실전 CLI 주문은 `KIS_ENV=live`, `STOCKCAST_ALLOW_LIVE=true`, 명령의
`--live-confirm LIVE`가 모두 필요합니다.

## 구조

- `config.py`: 환경 파일과 설정 검증
- `kis.py`: OAuth, 호출 제한, 시세·분봉·순위·잔고·주문 API
- `strategy.py`: SMA 교차 및 추세 돌파 신호
- `autotrade.py`: 모의 데이트레이딩 후보 선별과 실행 루프
- `web.py`: Flask 세션, CSRF와 대시보드 API
- `templates/`, `static/`: 웹 화면
- `tests/`: 외부 호출을 모킹한 전략·API·위험·웹 테스트

## 테스트

```powershell
python -m unittest discover -s tests -v
python -m compileall -q src
node --check src\stockcast\static\app.js
```

KIS 경로와 TR ID는 한국투자증권 공식
[Open Trading API 샘플](https://github.com/koreainvestment/open-trading-api)을 기준으로 합니다.
